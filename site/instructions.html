Complete operating guide

Nastech TTS instructions for every local user.

Use the installer when you want the simplest desktop setup. Use the Python route when you contribute to the project or need direct command-line control. Both run speech locally after required files are installed.

1. Install

Choose the route that fits your computer.

Desktop installer

From a clone of the repository, run the cross-platform installer. The normal graphical route hides the terminal; the flag shown below uses the available local platform configuration.

git clone https://github.com/bantuinversions/nastech-tts.git
cd nastech-tts
./installer/install.sh -- platforms

On Windows, use installer\install.ps1. On macOS and Linux, use installer/install.sh.

Python source route

Use a virtual environment and install the editable local package.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'

Windows PowerShell activation uses .venv\Scripts\Activate.ps1.

2. First local speech

Open the Voice Studio or use a command.

Browser Voice Studio

nastech-tts serve

Open http://127.0.0.1:8765/. Pick a theme, voice, emotion, rate, sound cue, and language, then select Generate & play. The player and download button appear after local synthesis completes.

Command-line speech

printf '<speak voice="siya">Hello from Nastech Research.</speak>' > hello.xml
nastech-tts synthesize hello.xml --output hello.wav

Every synthesis also writes a JSON manifest unless you supply a different manifest destination.

3. Voices and expression

Use named voices and explicit markup.

List available voices

nastech-tts voices

The ordered English list includes named Siya, Nasi, Jafta, Della, Axam, Alicia, Shanice, Adam, Shakira, and Shimah, plus delivery variants.

Add emotions

<emotion name="happy" intensity="0.72">
  This is a happy response.
</emotion>

Core values are neutral, calm, happy, excited, surprised, sad, angry, frustrated, fearful, and disgusted.

Add a sound cue

<sound type="laugh" />
<sound type="sigh" />

Available cues are laugh, chuckle, sigh, cough, sniffle, groan, yawn, gasp, cry, scream, and throatclear.

4. Bantu language packs

Download one exact pack only when you select it.

Start with the catalog and use code-first labels. An on-demand route is a pack availability state, not a claim that all routes have equal human voice-review evidence.

nastech-tts languages
nastech-tts language-packs
nastech-tts download-language-pack lg   # lg - Luganda
nastech-tts download-language-pack sw   # sw - Kiswahili
nastech-tts download-language-pack bem  # bem - Bemba

Planned language targets are listed without a replacement model. If a pack has no auditable local route, Nastech TTS refuses substitution rather than speaking the wrong language.

5. AI-agent responses

Inspect, plan, then generate a local response.

nastech-tts agent-capabilities
nastech-tts agent-markup "That is remarkable." --emotion awe --sound laughter
nastech-tts agent-speak "I am ready to help." \
  --voice siya --emotion joyful --sound laughter --output response.wav

Aliases such as joyful, awe, relieved, anxious, and triumphant map transparently to verified local controls. The JSON result tells the agent what actually rendered.

6. Nastech Agent connection

Register the local MCP voice bridge.

./installer/install.sh -- platforms
nastech

The installer preserves existing ~/.nastech/config.yaml entries and registers local tools for speech, status, and capabilities. Restart Nastech Agent after installation so it discovers the bridge.

7. Safe long-form use

Make long conversations measurable.

For long material, split the script into bounded turns or paragraphs, retain each manifest, and concatenate only after checking every segment. The scheduled endurance suite uses the same approach for a two-hour deterministic dialogue: it records chunk counts, elapsed minutes, real-time factor, sample format, clipping, DC offset, and a small listening excerpt. It does not claim that one successful runner guarantees every machine, pack, or future version.

make verify
python scripts/validate_language_self_test.py
nastech-tts status

Troubleshooting

Check the local service first.

What you seeWhat to do
The browser page does not open.Run nastech-tts serve, then open exactly http://127.0.0.1:8765/. Do not use a different port unless you selected one.
A language cannot speak.Run nastech-tts language-preflight CODE, then download an exact pack only if the route is marked adapter available.
Generation takes time on the first request.The first local request loads the selected model. Use nastech-tts warmup when you want to prepare the local English runtime before a conversation.
An agent cannot find TTS capabilities.Re-run the installer, restart Nastech Agent, and call nastech_tts_capabilities before speech generation.

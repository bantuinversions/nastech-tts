Install, run, listen.

01

Get the project

git clone https://github.com/bantuinversions/nastech-tts.git
cd nastech-tts
02

Install locally

./installer/install.sh -- platforms

The normal installer detects the platform and prepares a local environment.

03

Open the studio

nastech-tts serve

Open http://127.0.0.1:8765/, then select Generate & play.

The local runtime runs without a speech cloud proxy. Optional language packs are downloaded only when you choose them. Read the full installation and operating instructions before use.

AI agent voice responses

Let an agent ask, verify, then speak locally.

Agents can discover the exact runtime contract before they generate a response. Natural phrases such as joyful, awe, or triumphant resolve transparently to supported local controls.

Discover current controls

nastech-tts agent-capabilities

Returns machine-readable voices, languages, ten core emotions, eleven sound cues, aliases, rates, volumes, and explicit rendering limits.

Generate a local AI response

nastech-tts agent-speak \
  "I am ready to help." \
  --voice siya \
  --emotion joyful \
  --sound laughter \
  --sound sigh \
  --output response.wav

Writes a WAV, a manifest, and JSON that states the requested and rendered emotional controls.

Long conversation reliability

Two hours, measured—not claimed.

The scheduled endurance suite renders a deterministic two-hour English dialogue as bounded local segments, concatenates it to a two-hour WAV, and records timing, real-time factor, duration, WAV levels, clipping, chunk completion, memory observations, and a reproducible manifest. The large WAV is not committed or published as a Pages asset.

Conversation contract

Alternating Nastech Research turns, named voices, emotion transitions, pauses, and sound cues exercise production-style dialogue without a cloud service.

Quality gates

The run fails for missing chunks, an incorrect duration, clipping, unexpected sample format, unsafe DC offset, or a failed local response request.

Published evidence

The workflow uploads the JSON analysis, chunk manifest, and a short listening excerpt. It records minutes required rather than guessing a universal speed.

A successful endurance report proves the documented runner, hardware, dependency revision, and input completed that run. It is evidence for that environment, not a blanket guarantee for every computer, language pack, or future model revision.
